# SANI GROUP LOTO — ULTRA PREMIUM BLACK GOLD

## Запуск
На Windows не открывайте `index.html` двойным кликом. Это режим `file://`, в котором браузер блокирует API-запросы к серверу.

### Самый простой способ
1. Установите Node.js 18+.
2. Дважды нажмите `START.bat`.
3. Игра откроется на `http://localhost:3000/`.

Или в терминале папки: `npm start` и откройте `http://localhost:3000/`.

## Важно
Сервер является частью игры: он хранит пользователей, VIP, деньги/монеты, магазин, онлайн-комнаты, розыгрыш и админ-функции.

Админ-пароль по умолчанию: `admin123`.

Luxury Black Gold / SANI GROUP. Без старого коричневого деревянного интерфейса.
