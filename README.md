# Лото Онлайн: Классика

## Запуск
Никаких зависимостей ставить не нужно — сервер написан на чистом Node.js.
```
npm start
```
(или просто `node server.js`)

Затем открыть в браузере: http://localhost:3000

## Файлы
- `server.js` — Express-сервер: раздаёт статику, хранит валюту/прогресс игрока в `db.json` (создаётся автоматически), отдаёт лидерборд и ежедневные награды.
- `index.html`, `style.css`, `script.js` — клиентская часть: меню, магазин, маркеры, профиль, ежедневные награды, лидерборд и сама игра в лото против двух ботов (NEON, Anti_Petuh).

## Логика игры
- У игрока 3 карточки 3×9 (по 5 чисел в строке), числа от 1 до 90.
- Числа выпадают автоматически каждые 4 секунды (кружок сверху), нужно кликать по выпавшим числам на своих карточках.
- Побеждает тот, кто первым полностью закроет одну из карточек (боты играют "честно", иногда пропускают число, чтобы у игрока был шанс).
- Усиления (покупаются за 🪙): 👁 отметить текущее число, ✖ отметить все пропущенные выпавшие числа, +1 / +5 — ускорить розыгрыш.
- Валюта и прогресс сохраняются на сервере, привязаны к случайному ID в localStorage браузера (без регистрации).
