# Лото Онлайн — SANI GROUP

## Запуск
1. Установите Node.js 18+.
2. В корне проекта выполните `node server.js` или `npm start`.
3. Откройте `http://localhost:3000`.

Файлы клиента находятся в `generated/`: `index.html`, `style.css`, `client.js`.

Для админки можно задать пароль через переменную окружения `ADMIN_PASSWORD`. Если её нет, для совместимости используется `admin123` — рекомендуется сразу изменить пароль.
