# Лото Онлайн — SANI GROUP

Премиальная версия с графическим интерфейсом, столами друзей, чатом и расширенной админ-панелью.

## Запуск
1. Node.js 18+
2. `npm install` (зависимостей нет, команда необязательна)
3. `npm start`
4. Открыть `http://localhost:3000`

## Админка
Кнопка `🔑 Админка` находится внизу меню. Пароль по умолчанию: `admin123`. Для сервера лучше задать переменную окружения `ADMIN_PASSWORD`.

Администратор может: блокировать/разблокировать игрока, выдавать деньги и монеты, включать/выключать VIP и отправлять персональные сообщения.
