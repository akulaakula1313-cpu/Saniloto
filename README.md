# Лото Онлайн — SANI GROUP v8

## Запуск

1. Node.js 18+.
2. В корне проекта: `npm start` или `node server.js`.
3. Открыть `http://localhost:3000`.

Для админки рекомендуется задать `ADMIN_PASSWORD`. Если переменная не задана, для совместимости используется `admin123`.

## Важные изменения v8
- Полностью проверен и исправлен синтаксис клиента и сервера.
- Сервер авторитетно ведёт стол, банк, ставки и победу.
- Поддерживаются столы на 2–6 игроков.
- Выход до начала игры возвращает ставку.
- Выход во время игры оставляет ставку в банке.
- Если все игроки отключились, ставки возвращаются.
- Heartbeat обнаруживает закрытие вкладки/потерю соединения.
- Победитель получает банк только один раз.
- Проверка победы выполняется сервером по серверной карточке игрока.
- Магазин и покупка маркеров проходят через сервер.
- Админ: бан/разбан, деньги, монеты, VIP, SMS и очистка базы.
- Уведомления денег, монет, VIP и SMS разделены по типу.
